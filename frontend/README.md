# 智能安全监控系统 - 前端

基于 Vue 3 + TypeScript + Element Plus 的现代化监控系统前端

## 技术栈

- Vue 3 + TypeScript
- Vite
- Pinia (状态管理)
- Vue Router
- Element Plus (UI组件)
- Video.js (HLS视频播放)
- ECharts (图表)
- Axios (HTTP客户端)

## 安装和运行

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 生产构建
npm run build
```

## 默认账号

- 用户名: admin
- 密码: admin123

## 主要功能

1. **数据看板** - 视频监控 + 实时预警 + 统计图表
2. **视频管理** - 上传视频、自动转码HLS
3. **危险行为管理** - 配置检测类型
4. **阈值配置** - 调整预警灵敏度
